HOW TO UPLOAD TO GITHUB
1. Open your GitHub repository.
2. Tap Add file > Upload files.
3. Upload index.html, style.css, script.js and README.txt, plus the complete assets folder (keep the folder name assets).
4. Scroll down and tap Commit changes.
5. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for the Pages URL to appear. If your custom domain is connected, ensure its DNS records point to GitHub Pages and add the domain in Pages settings.
