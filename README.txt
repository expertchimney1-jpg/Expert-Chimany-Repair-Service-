UPLOAD TO GITHUB:
1. Extract this ZIP on your phone/computer.
2. Open your website repository on GitHub.
3. Choose Add file > Upload files.
4. Upload index.html, style.css, script.js, README.txt and the entire assets folder (not the ZIP itself).
5. Commit changes.
6. If using GitHub Pages, open Settings > Pages and select the correct branch/root folder.
7. Set your domain DNS records as required by your domain provider and GitHub Pages.
